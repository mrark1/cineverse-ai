# CineVerse AI – AI Development Prompts

This document contains the AI prompts used during the development of **CineVerse AI**, a Netflix-inspired Movie Discovery Web Application built as part of the **Prodesk IT Sprint 8 Internship**.

---

# Project Overview

Project Name: CineVerse AI

Framework: React + Vite

Language: JavaScript

Styling: CSS3

API: TMDB API

State Management: React Context API

Storage: LocalStorage

Deployment: Vercel

---

# Prompt 1

**Objective**

Create a Netflix-inspired movie discovery application using React and Vite.

**Prompt**

> Build a modern Netflix-inspired Movie Discovery Web Application using React + Vite. The application should fetch popular movies from TMDB API, display movie cards with posters, ratings, release dates, and support responsive layouts for mobile and desktop.

---

# Prompt 2

**Search Functionality**

**Prompt**

> Implement a movie search feature using the TMDB Search API. Include a 500ms debounce mechanism to prevent unnecessary API requests while typing.

---

# Prompt 3

**Infinite Scroll**

**Prompt**

> Replace traditional pagination with Infinite Scroll using the Intersection Observer API. Automatically fetch the next page of movies when the user reaches the bottom of the page.

---

# Prompt 4

**Favorites**

**Prompt**

> Implement a Favorites system using React Context API and LocalStorage. Users should be able to add and remove movies from Favorites, and the data should persist after page refresh.

---

# Prompt 5

**Dark / Light Theme**

**Prompt**

> Create a fully responsive Dark and Light theme using React Context API and CSS Variables. Persist the selected theme using LocalStorage.

---

# Prompt 6

**Responsive Design**

**Prompt**

> Make the application fully responsive for 320px mobile devices, tablets, laptops, and desktop screens using CSS Grid, Flexbox, and media queries.

---

# Prompt 7

**Performance Optimization**

**Prompt**

> Optimize the application by implementing image lazy loading, reusable components, optimized API calls, and efficient React state management.

---

# Prompt 8

**User Experience**

**Prompt**

> Improve the user experience by adding loading indicators, skeleton loading, hover animations, smooth transitions, toast notifications, and responsive navigation.

---

# Prompt 9

**Code Quality**

**Prompt**

> Refactor the project into reusable React components with clean folder structure, maintainable code, and consistent naming conventions following modern React best practices.

---

# Prompt 10

**Deployment**

**Prompt**

> Prepare the application for production deployment on Vercel with environment variables, optimized build configuration, and a professional README.
